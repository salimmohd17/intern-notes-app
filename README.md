## 🚀 Task 1: Notes Application

Full-stack Notes Application built with **Node.js, Express, React (Vite), and SQLite (`node:sqlite`)**.

### Quick Start
```bash
# 1. Seed database
npm run seed:task1

# 2. Start Backend API (runs on http://localhost:5000)
npm run backend:task1

# 3. Start Frontend Client in another terminal (runs on http://localhost:3000)
npm run frontend:task1
```

For complete documentation, database schema definitions, API contracts, and architecture diagrams, see [`task1-notes-app/README.md`](./task1-notes-app/README.md).
